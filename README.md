# Portfólio — Diego Garcia

Portfólio estático de desenvolvedor back-end, pronto para GitHub Pages. Não há build, dependências ou runtime de servidor.

## Executar

Abra `index.html` diretamente ou use qualquer servidor HTTP estático.

## Estrutura

- `index.html`: conteúdo e marcação semântica
- `css/style.css`: sistema visual responsivo
- `js/main.js`: menu, navegação ativa e scroll reveal
- `assets/images/retro-workstation.png`: arte principal
- `assets/cv/diego-garcia-curriculo.html`: currículo para download
- `favicon.svg`: ícone do site

## Atualizar o currículo

Substitua o arquivo em `assets/cv/` e ajuste os dois links de download em `index.html` se o nome mudar.
